# 부광 말씀씨앗 서버 동기화 버전

부광교회 교회학교와 가정을 위한 성경 암송·복습 웹앱입니다.  
이 버전은 기존 모바일 설치 기능에 더해, Supabase를 연결하면 여러 휴대폰에서 같은 말씀 목록과 암송 기록을 함께 사용할 수 있습니다.

## 포함 기능

- 학생 / 교사 / 교역자 / 관리자 계정 구분
- 관리자 비밀번호: `1369`
- 관리자만 말씀 추가·수정·삭제 가능
- 암송구절별 암송 번호 입력 가능
- 빈칸 암송, 전체 가리기, 직접 입력 확인
- 1일·3일·7일·14일·30일·60일 복습 주기
- 복습하기는 한 번이라도 오탈자 없이 `외웠어요`를 누른 말씀만 표시
- `복습 완료` 빠른 버튼 제거
- 오탈자 없이 암송한 말씀은 `내가 암송한 말씀` 탭에 자동 저장
- 주간 암송 순위
- 관리자 문구 변경
- 관리자 배경 디자인 변경
- 데이터 백업 / 가져오기
- 모바일 홈 화면 설치 안내
- Supabase 서버 동기화 선택 지원

## 서버 없이 사용하기

그냥 압축을 풀고 `index.html`을 열면 기존처럼 로컬 저장 방식으로 사용할 수 있습니다.  
이 경우 각 기기 데이터는 서로 따로 저장됩니다.

## 서버 있는 방식으로 사용하기: Supabase 연결

### 1. Supabase 프로젝트 만들기

1. Supabase에서 새 프로젝트를 만듭니다.
2. 프로젝트가 만들어지면 Dashboard의 `SQL Editor`로 들어갑니다.
3. 이 폴더의 `supabase_schema.sql` 내용을 복사해서 한 번 실행합니다.

### 2. URL과 anon key 복사하기

Supabase Dashboard에서 다음 값을 확인합니다.

- Project URL
- anon public key

보통 `Project Settings → API` 메뉴에서 확인할 수 있습니다.

### 3. config.js 수정하기

이 폴더의 `config.js` 파일을 메모장이나 VS Code로 열고 아래처럼 수정합니다.

```js
window.MALSEUM_SSIAT_SERVER = {
  mode: "supabase",
  supabaseUrl: "https://여기에-프로젝트주소.supabase.co",
  supabaseAnonKey: "여기에-anon-public-key",
  table: "malseum_ssiat_app_state",
  appId: "bugwang-malseum-ssiat"
};
```

### 4. 웹에 올리기

`bugwang-malseum-ssiat-app` 폴더 전체를 Netlify, GitHub Pages 같은 정적 호스팅에 올립니다.  
그 주소를 학생/교사/교역자에게 공유하면 같은 서버 데이터를 불러옵니다.

## 동기화 방식

- 앱이 열릴 때 서버 데이터를 불러옵니다.
- 관리자가 말씀, 문구, 배경, 계정, 기록 등을 바꾸면 서버에 저장됩니다.
- 관리 탭의 `서버 동기화`에서 수동으로 다시 불러오거나 현재 데이터를 서버에 올릴 수 있습니다.

## 중요한 보안 안내

이 버전은 교회학교 내부 테스트와 소규모 운영을 위한 간단 서버 동기화 버전입니다.  
관리자 비밀번호 `1369`는 앱 안에서 동작하는 기본 보호 장치입니다. 실제 공개 배포나 장기 운영에서는 Supabase Auth, 서버 함수, 권한 정책을 더 엄격하게 붙이는 것이 좋습니다.

## 휴대폰 홈 화면에 설치하기

### 안드로이드

1. Chrome으로 앱 주소를 엽니다.
2. 오른쪽 위 `⋮` 메뉴를 누릅니다.
3. `앱 설치` 또는 `홈 화면에 추가`를 선택합니다.
4. 홈 화면의 `부광 말씀씨앗` 아이콘으로 실행합니다.

### 아이폰/iPad

1. Safari로 앱 주소를 엽니다.
2. 아래쪽 공유 버튼을 누릅니다.
3. `홈 화면에 추가`를 선택합니다.
4. 이름이 `부광 말씀씨앗`인지 확인하고 추가합니다.

## 이번 수정: 홈 화면 암송구절 넘기기

홈 화면의 `암송구절` 영역은 손가락으로 옆으로 밀거나, `이전 구절` / `다음 구절` 버튼을 눌러 다음 암송구절을 볼 수 있습니다.
서비스워커 캐시 버전을 올려 이전 화면이 계속 보이는 문제도 줄였습니다.
