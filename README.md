# 부광 말씀씨앗 v21 — 편한 데스크톱 설정창과 별도 관리자 모드

v21은 앱을 열면 지금처럼 가입 없이 바로 시작합니다. 설정창에서 원할 때 계정을 연결하거나, 별도 버튼으로 관리자 모드에 들어갈 수 있습니다.

1. **가입 없이 사용**: 앱을 열자마자 이 기기 전용 기록으로 시작합니다.
2. **계정으로 사용**: 아이디와 숫자 6자리 번호를 만들면 현재 기록이 계정으로 옮겨지고, 휴대폰과 컴퓨터에서 같은 기록을 이어갑니다.

관리자 역할은 회원가입 화면에 없으며 Supabase에서 별도로 지정합니다. 일반 사용자 세션과 관리자 세션은 서로 분리되어, 관리자 모드로 들어가도 기존 일반 사용 기록이 사라지지 않습니다.

## 작동 방식

- 새 기기에서는 Supabase 익명 사용자가 자동 생성됩니다.
- 익명 사용자는 다른 사람의 기록을 읽을 수 없고 현재 기기에서만 같은 기록으로 돌아올 수 있습니다.
- 익명 사용자가 계정을 만들면 `register-account` 함수가 현재 개인 기록을 새 영구 계정으로 복사한 뒤 자동 로그인합니다.
- 다른 기기에서는 `기존 계정 로그인`을 누르고 같은 아이디와 숫자 6자리 번호를 입력하면 기록이 동기화됩니다.
- 로그인 상태는 기기에 보관되므로 매번 다시 로그인하지 않습니다.
- 일반 사용자는 `admin` 역할을 선택하거나 스스로 관리자 권한을 얻을 수 없습니다.
- 설정창의 `관리자 모드로 들어가기`를 누르면 저장된 관리자 계정이 있을 때 바로 들어가고, 처음이면 관리자 아이디와 숫자 6자리 번호를 묻습니다.
- 관리자 작업을 마치면 설정창의 `일반 모드로 돌아가기`를 눌러 원래 기기 전용 또는 일반 계정으로 돌아갑니다.

## 배포 순서

### 1. 데이터베이스 보안 스키마

Supabase SQL Editor에서 `supabase_schema.sql` 전체를 실행합니다. v18 스키마를 이미 성공적으로 실행했다면 같은 보안 구조를 사용하므로 다시 실행해도 안전합니다.

### 2. 익명 로그인 — 필수

Supabase Dashboard의 **Authentication → Sign In / Providers → Anonymous Sign-Ins**를 켭니다.

### 3. 선택형 계정 생성 함수 — 필수

`register-account` Edge Function을 배포합니다. 이 함수는 현재 익명 사용자를 확인하고, 새 계정을 만든 뒤 지금까지의 암송 기록을 옮깁니다. 관리자 키는 브라우저에 노출되지 않습니다.

```bash
supabase functions deploy register-account --no-verify-jwt
supabase secrets set ALLOWED_ORIGINS=https://dusdnaks-crypto.github.io
```

비밀번호 초기화 기능까지 사용하려면 다음 함수도 배포합니다.

```bash
supabase functions deploy admin-reset-pin --no-verify-jwt
```

`SUPABASE_URL`과 `SUPABASE_SERVICE_ROLE_KEY`는 Supabase가 함수에 제공하는 서버 환경변수입니다. `service_role` key를 `config.js`, GitHub 또는 앱 화면에 절대로 넣지 마세요.

### 4. 관리자 별도 지정

목사님이 앱에서 일반 계정을 하나 만든 뒤 SQL Editor에서 아래 아이디를 실제 아이디로 바꾸어 실행합니다.

```sql
update public.malseum_ssiat_profiles
set member_role = 'admin'
where username = '관리자아이디';
```

지정이 끝나면 앱의 `내 계정` → `관리자 모드로 들어가기`에서 같은 아이디와 숫자 6자리 번호로 로그인합니다. 일반 가입 화면에는 관리자 선택지가 없습니다.

### 5. GitHub Pages 배포

이 폴더 안의 파일들을 GitHub 저장소 최상위에 덮어씁니다. 압축파일이나 바깥 폴더를 올리는 것이 아니라 `index.html`, `app.js`, `style.css` 등이 저장소 최상위에 보여야 합니다.

배포 후 시크릿 창에서 공개 링크를 열어 다음을 확인합니다.

- 가입 화면 없이 홈이 바로 열리는지
- 설정에 `계정 만들어 연동하기`와 `기존 계정 로그인`이 보이는지
- 계정을 만든 뒤 현재 기록이 유지되는지
- 다른 브라우저에서 같은 계정으로 로그인했을 때 기록이 나타나는지
- 일반 계정에는 관리자 편집 기능이 나타나지 않는지
- 컴퓨터에서 설정창이 화면 안에 맞고, 내용이 길면 창 안에서 스크롤되는지
- 관리자 버튼으로 들어간 뒤 `일반 모드로 돌아가기`가 보이는지

## 사용상 차이

| 사용 방식 | 가입 | 같은 기기 자동 시작 | 휴대폰·컴퓨터 연동 | 데이터 삭제 후 복구 |
| --- | --- | --- | --- | --- |
| 기기 전용 | 없음 | 가능 | 불가 | 불가 |
| 일반 계정 | 선택 | 가능 | 가능 | 다시 로그인하여 가능 |
| 관리자 계정 | 별도 지정 | 가능 | 가능 | 다시 로그인하여 가능 |

## 설치

- Android Chrome: 앱 주소 접속 → `앱 설치하기`, 또는 Chrome `⋮` → `앱 설치`
- iPhone Safari: 공유 버튼 → `홈 화면에 추가`

브라우저 보안 정책상 사용자의 최종 설치 확인을 앱이 대신 누를 수는 없습니다.
