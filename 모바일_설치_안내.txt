부광 말씀씨앗 v22 모바일 사용 안내

가입 없이 사용하기
1. 앱 주소를 열면 바로 시작됩니다.
2. 이 기록은 현재 휴대폰에서만 이어집니다.

휴대폰과 컴퓨터에서 함께 사용하기
1. 설정 → ‘계정 만들어 연동하기’를 누릅니다.
2. 아이디, 이름, 부서, 구분, 숫자 6자리 번호를 입력합니다.
3. 현재 휴대폰 기록이 새 계정으로 옮겨지고 자동 로그인됩니다.
4. 컴퓨터에서는 설정 → ‘기존 계정 로그인’을 눌러 같은 아이디와 번호로 로그인합니다.
5. 이후에는 각 기기에서 자동 로그인됩니다.

Android Chrome
- 화면의 ‘앱 설치하기’를 누릅니다.
- 버튼이 ‘설치 방법 보기’라면 Chrome 오른쪽 위 ⋮ → ‘앱 설치’ 또는 ‘홈 화면에 추가’를 누릅니다.

iPhone/iPad Safari
- Safari 공유 버튼 → ‘홈 화면에 추가’를 누릅니다.

주의
- 가입 없이 사용한 기록은 앱 삭제·브라우저 데이터 삭제·기기 변경 뒤 복구되지 않습니다.
- 계정을 만든 기록은 다른 기기에서 다시 로그인하여 이어갈 수 있습니다.
- 관리자 권한은 담당자가 서버에서 별도로 지정합니다.
- 관리자 모드는 설정 → ‘관리자 모드로 들어가기’에서 엽니다.
